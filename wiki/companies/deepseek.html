DeepSeek（深度求索）

本库报告把 DeepSeek 视为中国开源基础模型与成本效率路线的标志性公司。2026-07-22 的第三方会议语录汇编进一步显示，公司自述的唯一主线是提高做成 AGI 的概率，而非当前产品、流量或利润最大化。

⚠️ 本页关于战略、组织和融资的新增内容来自 source_quality: third_party 的 elsewhere 二次汇编，不是公司公告或经确认的逐字访谈；其中部分措辞可能与原话有出入。

公司速览

  • 技术定位：华西证券 2026-06-24 把 DeepSeek-R1 作为“效率优先”范式案例，核心是 MoE 稀疏激活、MLA、FP8、GRPO 与蒸馏；该报告引用的 R1 训练成本约 557 万美元是行业报告口径。
  • 技术路线：梁文锋据 2026-07-22 媒体汇编把路线排为 CoT→Agent→持续学习→AI 自迭代→具身智能；现阶段优先 Coding Agent / 通用 Agent，垂直 Agent、多模态、幻觉治理和 3D/视频生成不是主线。
  • 产品策略：产品被视为 AGI 路径的副产物，不追求成为超级 App；下一代模型首先要帮助内部研发，而非优先优化外部用户体验。
  • 商业模式：公司据汇编称只赚合理利润、不追求利润最大化，开源模型与自部署模型一致，API 以少量人员维护，距离彻底商业化仍很远。
  • 竞争壁垒：成本排第一、研发时间第二、用户体验第三；低成本的意义不仅是降价，也是在算力有限时支持更大模型。
  • 资源与格局：汇编把中外差距主要归因于资源而非人才，并判断国内基础模型厂商最终可能收敛为“两家大公司、两家小公司”，模型厂不会拿走 AI 行业大部分利润。
  • 组织约束：愿景驱动而非 KPI 驱动，自上而下任务与自下而上探索各约一半；团队稳定性被称为唯一不可退让事项，本轮融资据称缓解了该风险，但融资条款未披露。

关键分歧跟踪

⚠️ 行业商业化窗口 vs 公司主动克制：华西证券 2026-06-24 认为 2025-2026 是大模型商业化关键窗口，私有化部署、一体机和续费率是价值兑现路径；DeepSeek 语录汇编则称彻底商业化仍很遥远、API 收入吸引力有限。行业机会与 DeepSeek 自身选择不能互相替代。

⚠️ Agent 的需求侧与研发侧含义：华西证券把 Agent 视为应用和 Token 需求增长点；DeepSeek 把 Coding Agent / 通用 Agent 首先视为内部研发工具和通往持续学习的阶梯。

⚠️ 效率并非否定 Scaling：行业常把 DeepSeek 归入“少算力”范式；汇编中的梁文锋明确相信 Scaling，并把低成本定义为在资源约束下训练更大模型的手段。

⚠️ 来源等级：训练成本与技术栈来自持牌券商行业报告；战略、融资和组织内容来自媒体二次汇编。后者缺少会议原始录音与上下文，权重应更低。

待验证的催化剂

  • 下一代模型公开展示持续学习能力，并与长上下文、RAG 或外部记忆方案区分。
  • Coding Agent 显著缩短 DeepSeek 内部模型研发与工程迭代时间。
  • 开源权重与官方部署模型继续保持能力一致，可由许可证、评测和推理特性核验。
  • API 降价与单位推理成本同步下降，仍能实现公司所称“合理利润”。
  • 本轮融资金额、投资方、治理和算力采购由可信来源披露，团队稳定性改善。
  • 公司维持不做超级 App、弱化垂直 Agent/多模态/视频生成的优先级，或正式披露路线调整。
  • 国内基础模型市场向“两大两小”收敛，且基础模型利润占 AI 价值链比例可被量化。
  • 持续学习与 AI 自迭代之后出现可验证的具身智能研发或合作。
