Token 经济与词元工厂

Token Factory 是把电力、芯片、数据、模型和调度软件组织成规模化 AI 推理产线的产业框架。它与传统智算中心的区别不在“有没有 GPU”，而在经营单位由卡时/FLOPS 切换为满足质量、成功率和时延约束的有效 Token。

当前唯一系统来源为九章云极 DataCanvas 与 InfoQ 的产业白皮书（2026-06，third_party），其市场测算与厂商案例需要后续卖方研究、合同数据和可复现基准交叉验证。

产业链地图

上游生产要素
绿电/电网/储能 + GPU/NPU + HBM/存储 + 交换机/光模块 + 液冷
  ↓ 算-电-热-网协同
中游生产执行
训练工厂 + 推理引擎 + 异构调度 + 模型量化/缓存 + MaaS/API
  ↓ 标准化计量、SLA 与定价
下游价值实现
行业应用 + Agent/AaaS + 企业智能服务 + Token 跨境交付

主题接口：AI算力产业链 · AI算力芯片 · AIDC电力与供电架构 · 液冷 · CPO与光通信 · 大模型产业 · 算力政策与东数西算。

单位经济模型

报告提出的简化框架是：

物理产能 ≈ 可用电力 × Tokens/W

要变成可审计收入，还需补入：

收入 ≈ 可用电力 × Tokens/W × 负载率 × 有效Token率 × 单价

其中“有效 Token 率”需同时满足请求成功、质量和时延约束；忽略它会把低质量或失败输出也当成产能。

成本结构锚

九章云极/InfoQ 以 128 节点 H200、五年零残值折旧为例给出：GPU 折旧 60%、网络折旧 10%、机柜电费 8%、带宽+人力 10%、软件平台 10%、其他 2%。这说明单位成本的第一杠杆通常不是电费，而是利用率提升后摊薄硬件折旧；电价与 PUE 决定第二层差异。

核心运营指标

目标指标为什么重要
物理效率Tokens/W固定电力下的原始产出能力
有效产能eTPM同时扣除失败、质量不达标与时延不达标
交互体验TTFT、TPOT/ITL、E2E Latency区分首响、流式速度与完整响应时间
资源利用GPU/NPU 利用率、KV/前缀缓存命中率决定折旧与显存能否被充分摊薄
经济性单位有效 Token 成本、ROI把硬件、电力、运维与真实产出相连
可扩展性多节点 eTPM 线性扩展效率识别互联与同步开销是否吞噬扩容收益

主要技术路径：动态/连续批处理、FlashAttention、PagedAttention、Prefix Cache、投机解码、Prefill-Decode 分离、量化/剪枝、异构算力调度、液冷与算电协同。

行业关键争议

⚠️ 计量争议：不同模型的 Token 切分和质量不同，数量未必跨模型可比；若无 eTPM/质量口径，“Token 大宗商品化”仍缺标准基础。

⚠️ 盈利争议：白皮书称 Token 分成可把毛利率推至 40%–50%+、回收期缩至约 2 年，但没有披露可复核合同与现金流；固定成本高也意味着负载率不及预期时利润反向放大下滑。

⚠️ 折旧争议：示例采用 5 年折旧，而报告同时承认 AI 硬件约两年迭代一代；经济寿命与会计寿命错配可能低估减值。

⚠️ 价格争议：报告假设“成本降、价格稳”，但模型/API 价格竞争可能使售价下降快于成本，需持续跟踪每百万输入/输出 Token 的真实成交价。

关键观察指标

  • 电力：可用 GW、并网周期、绿电价格、PUE 与机柜功率密度。
  • 供给：高端 GPU/NPU 交期、HBM 与高速互联瓶颈、国产异构适配效率。
  • 运营：负载率、eTPM、TTFT/TPOT、缓存命中率、故障率与 SLA。
  • 价格：不同质量/时延层级的输入与输出 Token 报价、折扣与分成比例。
  • 需求：MaaS/API/Agent 调用量、企业续费率、离线与实时推理占比。
  • 财务：单位有效 Token 成本、折旧/减值、资本回收期和经营现金流。

催化剂对账

  • 出现统一或可映射的 Token 质量、能效、eTPM 与 SLA 标准。
  • “东数西算”枢纽披露按有效 Token 结算的规模化合同与负载率。
  • 国产芯片集群披露可复现的多节点 eTPM、TTFT/TPOT 与单位成本。
  • Token 跨境服务形成明确的数据合规与结算机制。
  • 第三方基准验证动态批处理、PagedAttention、异构调度等技术的真实降本幅度。
