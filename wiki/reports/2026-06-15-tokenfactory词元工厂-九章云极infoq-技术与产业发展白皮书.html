九章云极 DataCanvas & InfoQ·Token经济：Token Factory（词元工厂）技术与产业发展白皮书（2026-06）

⚠️ 本报告由九章云极 DataCanvas 与 InfoQ 联合出品，属于产业机构白皮书而非持牌卖方研究；行业数据多引自公开资料与第三方预测，九章智算云案例为厂商自述，可信度与可复现性需自行判断。原文仅标“2026 年 6 月”，本卡以 6 月 15 日作为时间线占位，并非精确发布日期。

一句话论点

九章云极 DataCanvas 与 InfoQ 认为，AI 产业的评价尺度正从 GPU 数量与峰值 FLOPS 转向“单位电力可生产多少高质量 Token”；Token Factory 将电力、芯片、数据与算法组织成工业化推理产线，商业模式由卖卡时升级为按 Token/智能结果收费，其胜负取决于 Tokens/W、有效 Token 产能、单位 Token 成本与算电协同，而非单纯堆叠算力。

核心逻辑链

  1. 事实：报告引国家数据局口径称，中国日均 Token 调用量两年内由 1,000 亿增至 140 万亿；引艾媒咨询称 2025 年中国词元调用总量 24,619.3 万亿次，预计 2026/2030 年分别为 111,799.5/7,046,680.4 万亿次（原文P3·图1）。
  2. 判断：推理与 Agent 调用增长，使 Token 从模型内部计量单位转为可计量、可计费的智能服务商品；AI 基础设施的核心产出也由 FLOPS 变为有效 Token。
  3. 判断：在电力约束下，产能上限可概括为“每瓦 Token 产出 × 可用电力规模”。因此高能效芯片、液冷、集群调度、模型量化、缓存与绿电成本共同决定单位 Token 成本。
  4. 判断：成本端以 GPU 折旧为主，固定成本占比高；当利用率和 Token 产能提升时，折旧被摊薄，按 Token 分成的盈利弹性可能高于传统卡时租赁。
  5. 判断：价值链从上游能源/芯片/网络，经中游模型与云平台，传导至下游 API、MaaS 与 Agent；中国的相对优势被概括为低成本绿电、工程化效率、完整生态与“东数西算/Token 出海”。

⚠️ “收入 = Tokens/W × 可用千兆瓦数”在原文脚注中已说明只是固定电力约束下的产能/收入上限框架，并非完整收入公式；缺少 Token 售价、有效率、负载率、SLA 与资本成本等变量，不能直接用于估值。

盈利框架

  • 报告引中金公司 2026 年 5 月研报及润建股份测算称，传统算力租赁毛利率约 20%–30%，Token 工厂经细切、分时复用和模型优化可达 40%–50%，自建算力场景或 60%+。
  • 报告引润建股份公开测算称，Token 分成模式回收期约 2 年，传统算租为 3–5 年；并称收入或为传统租赁的 5–10 倍、净利率可能由 10%–15% 升至 30%+（原文P11–12）。
  • 可信度提醒：上述口径缺少资本开支、负载率、价格、客户结构和现金流明细，属于企业/报告情景测算，不宜当作行业基准。

测算假设链

  • 需求假设：Token 调用量延续高增长，且 Agent/长上下文使有效推理需求快于传统 API 调用增长。
  • 电力假设：可用电力是产能硬上限；西部绿电 0.2–0.4 元/度、液冷 PUE 约 1.1 的项目条件能够获得并长期维持。
  • 利用率假设：128 节点 H200 集群可长期保持 70%+ 利用率，从而摊薄占总成本 60% 的 GPU 折旧。
  • 折旧假设：AI 硬件约两年迭代一代，但会计折旧使用 5 年、零残值；若经济寿命短于折旧寿命，单位成本与减值风险会被低估。
  • 价格假设：单位 Token 成本随芯片/软件效率下降，而服务售价因结构性需求保持相对刚性；若模型价格战快于降本，利润扩张不成立。
  • 有效性假设：产出的 Token 能满足成功率、质量与时延约束；只提高原始吞吐而不提高 eTPM，不构成真实产能增长。
  • 网络假设：高速互联、800G/1.6T 光模块与调度软件不会成为扩展瓶颈，多节点 eTPM 可接近线性增长。

结论会过时，以上假设链可用新的电价、PUE、芯片价格、负载率、Token 售价与 eTPM 重新代入。

产业链与参与者

能源/芯片/服务器/网络/存储 → 大模型与云平台/训练工厂/推理工厂 → API/MaaS/AaaS/行业 Agent

  • 上游生产要素：绿电与算电协同、高能效 GPU/NPU、超节点、交换机/光模块、存储与液冷。报告实质讨论 英伟达、华为、寒武纪、海光信息 等，但均非本篇主标的。
  • 中游生产执行：模型优化、异构算力调度、推理引擎、MaaS 与计量结算。报告重点展示九章云极 Alaya NeW，但九章云极是报告发布方，按库规不建公司页。
  • 下游价值实现：API 调用、行业 Agent、SaaS→MaaS→AaaS；价值评价从 Token 数量进一步转向 VpT（Value per Token）。
  • 基础设施接口：AI算力产业链、AI算力芯片、CPO与光通信、液冷、AIDC电力与供电架构、算力政策与东数西算。

中国路径与政策映射

  • 报告将中国优势概括为低成本绿电、国产模型与工程化效率、完整上中下游生态、超大应用市场，以及宁夏/甘肃等西部枢纽承接非实时推理。
  • “Token 出海”的基本路径是境内生产、跨境交付 AI 服务；其经济性依赖电价与模型价格差，其可行性还受数据跨境、芯片供应、模型合规与海外 SLA 约束。
  • 报告前言称中国电信宁夏分公司发布 174.38 亿元（含税）“Token 工厂”集采，作为产业从概念向基建项目迁移的标志；本卡未外部核验招标口径，保留为报告陈述。

催化剂与时间点

  • 国家/地方形成可对比的 Token 计量、质量与服务标准，特别是 eTPM、SLA 和能效口径。
  • “东数西算”枢纽出现更多按有效 Token 计费、而非按卡时出租的可审计合同。
  • 国产 GPU/NPU 与异构调度在千卡/万卡推理场景披露可复现的利用率、TTFT、TPOT 与成本数据。
  • 电价、PUE 与 Token 售价下降速度之间形成可持续的单位经济模型。
  • MaaS/AaaS 需求扩大并带动 Token 工厂负载率持续高于 70%。

风险提示

  • 电力供给、并网与绿电稳定性不足；PUE 与电价假设无法落地。
  • 高端 AI 芯片供应、地缘政治与国产软硬件生态适配风险。
  • 硬件迭代快于折旧，造成资产减值、利用率不足和回收期拉长。
  • 推理效率面临存储墙、互联、HBM 与算法边际收益下降等物理瓶颈。
  • Token 商品化缺少跨模型质量可比性；按数量计费可能激励低质量输出。
  • 模型/API 降价快于成本下降，报告假定的“价格稳、成本降”失效。
  • 数据隐私、内容安全、跨境合规与监管风险。
  • 厂商案例缺少客户名和复现条件，降本幅度存在选择性披露风险。

与前篇观点对比

  • 对比 2026-06-24-AI大模型行业深度-华西证券-效率革命：华西证券从模型/应用效率革命解释需求，本篇把效率进一步落到 Tokens/W、eTPM、TTFT/TPOT 和单位有效 Token 成本，补足推理基础设施的经营指标。
  • 对比 2026-06-30-算力政策专题-西部证券-数字中国建设算力新部署：西部证券提供全国一体化算力网、东数西算、PUE/国产化等政策硬约束；本篇提供“算力如何变成可计费 Token”的微观运营框架。
  • 对比 2026-07-07-互联网Capex-BofA-提高资本开支预测：BofA 用 GW 容量和 Capex 拆分刻画海外供给规模，本篇强调同一电力规模下的有效 Token 转化率。两者合并可形成“GW × Tokens/W × 有效率 × 单价”的完整收入桥。

⚠️ 核心分歧：本篇偏乐观地假设 Token 价格具刚性、分成模式显著提高毛利和回收速度；既有海外 Capex 研究更强调电力、融资与建设周期约束。高需求不自动等于高回报，仍需用真实负载率、价格与现金流验证。
