深入推进数字中国建设，算力领域有何新部署？（西部证券，2026-06-30）

西部证券国内政策专题报告，“洞察中国产业政策”系列之二。核心不是选股，而是梳理近期算力政策信号、提炼中国算力政策逻辑。结论：算力政策已从单一”新型基础设施”升维为”新型生产力 / 国家综合国力的重要体现”，形成”定位升维、目标多元化”+“国家主导、分级推进”+“建用并重”三大宏观特征；政策部署凸显六大主线（供给结构 / 空间布局 / 绿色低碳 / 安全保障 / 产业应用 / 市场机制），“十五五”开局落地为八大方向（智算集群 / 自主可控 / 算电协同 / 连算成网 / 市场化运营 / 算力出海 / 前沿技术 / 安全韧性）。是本库继财通宏观展望之后的第二篇自上而下报告，也是首篇”产业政策”报告——为全库自下而上的 AI算力产业链 提供政策需求锚。相关枢纽详见 算力政策与东数西算。

一、核心结论

  • 两会锚点·“六张网” + 7 万亿投资：2026 全国两会，国家发改委主任郑栅洁表示要推进”十五五”规划 109 项重大工程和项目、推进”六张网”和其他重点领域建设。六张网中明确可辨识的包括算力网、新型通信网、城市地下管网、物流网（另含能源/电力网、综合立体交通网等）；其他重点领域含消费、物流、低空、“人工智能+“、教育医疗等。初步估算相关投资约 7 万亿元；近期中央政治局会议、国常会等重磅会议均点到”六张网”。“算力网”是六张网落地新兴产业赛道的核心着力点。
  • 政策外延远超”建设”：我国算力政策不仅涉及基础设施建设与布局，还关乎算力能耗约束、算力运营与应用、关键科技自主可控、安全韧性等多领域。
  • 政策前瞻（第五部分）：未来仍有加码空间——或发布”十五五”数字经济发展规划、算力领域专项行动计划；短期围绕算电协同、连算成网、算力应用、人工智能治理的政策或陆续出台；资金端特别国债 / 政策性金融工具或向算力基础设施、关键设备采购、重大工程倾斜，地方财政补贴向算力倾斜；考核评价体系有望从”重建设”转向”重应用、重绩效”（覆盖算力利用率、调度能力、绿色低碳水平）。
  • 风险提示：①政策落地不及预期（跨部门协调、跨区域统筹、地方执行、企业投资意愿）；②AI 产业发展超预期（自主可控 / 能耗约束 / 供需结构 / 技术路径演变）；③海外算力叙事扰动（美股 AI 巨头 Capex 若收缩经产业链预期传导）；④地缘政治扰动或超预期。

三、算力顶层设计：三大特点（第二部分）

  1. 定位升维：从”基础设施”→“新型生产力”。“十四五”规划纲要将算力纳入”新型基础设施”、与 5G/数据中心并列；“十五五”规划纲要在”深入推进数字中国建设”篇单独成章部署”算力算法数据高效供给”，并把”全国一体化算力网”列为新型基础设施重大工程之首；丁薛祥进一步定调”算力是国家综合国力的重要体现”。
  2. 治理结构：国家主导、分级推进。中央通过”东数西算”、全国一体化算力网等顶层工程统筹规模/结构/空间布局与目标 → 地方基于国家规划制定方案、经批准后与国企（三大运营商、地方平台）协同落地 → 科技企业持续加码 AI 基建/云计算/芯片。对照美国：算力政策愈发成为”地缘政治竞争工具”（出口管制、投资审查收紧对华半导体出口；私企以技术生态+供应链联盟谋垄断），核心目标是维持全球竞争力。
  3. 效能转向：从”重建设”→“建用并重”。早期靠”东数西算”补规模短板；进入”十五五”，Token 爆发式应用推动算力从资源租赁向商业化服务转型，转入”建用并重、高效运营”新阶段——建设端聚焦智算集群/算电协同，使用端强化监测调度 + 政府购买/算力租赁/算力银行 + 算力券降低中小企业门槛。

表 1 梳理了 2020《政府工作报告》→2026”十五五”规划纲要的算力顶层设计时间线（新基建→全国一体化大数据中心→东数西算→算力基础设施高质量发展→全国一体化算力网）。

四、六大部署主线（第三部分）

3.1 供给结构——通算/智算/超算多元并举，智算凸显。《算力基础设施高质量发展行动计划》确立”多元供给”，“十五五”进一步聚焦”高性能高质量智算资源供给，论证建设超大规模智算集群”。

3.2 空间布局——“东数西算”八大枢纽 + 十大集群（表 3）。定位从”就近布局”转向”西部承接”：

  • 单一行政区枢纽（可再生能源丰富/气候适宜）：贵州（贵安）、内蒙古（和林格尔）、甘肃（庆阳）、宁夏（中卫）——原则上布局 1 个集群；
  • 跨区域枢纽（用户规模大/应用需求强）：京津冀（张家口）、长三角（长三角生态绿色一体化示范区 + 芜湖）、粤港澳（韶关）、成渝（天府 + 重庆）——原则上布局不超过 2 个集群。
  • 约束加码（表 4）：整体上架率 <50% 地区新建须加强论证；枢纽节点外原则上不新建大型/超大型数据中心；目标”枢纽节点新增算力占全国新增算力 60% 以上”（2025）。

3.3 绿色低碳——从能效向绿电、碳效多维。PUE 强制标准 ≤1.5；《数据中心绿色低碳发展专项行动计划》（2024）：2025 年底新建大型/超大型数据中心 PUE ≤1.25、枢纽节点 ≤1.2；“枢纽节点新建数据中心绿电占比 >80%“（2025）。算电协同已升至国家战略高度（政府工作报告”超大规模智算集群、算电协同等新基建工程”）。

3.4 安全保障——四方面：网络安全（数据中心集群同步建网络安全防护）/ 数据安全（《数据安全法》《个保法》分类分级）/ 供应链安全（高端芯片、核心软件”卡脖子”→自主可控，“十五五”提”加快培育自主可控、协同运行的软硬件生态”）/ 产业备份（西部异地灾备、国家算力保障基地；先进存储占比 30%+、重要数据灾备覆盖率 100%，2025 目标）。

3.5 产业应用——千行百业深度融合。“人工智能+“连续三年（2024–2026）写入《政府工作报告》；“十五五”把”全方位推进数智技术赋能”纳入数字中国核心任务，算力应用从”示范引领”向”规模普及”迈进。

3.6 市场机制——从政府主导到市场化运营。2020–2022 政府牵头、重建设轻运营；此后探索算网协同运营、跨区域调度，“提升算力服务普惠易用水平”；地方以算力券、模型券、算力补贴激励；上海提”算力期货研发准备”。
