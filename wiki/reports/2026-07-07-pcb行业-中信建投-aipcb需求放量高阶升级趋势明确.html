中信建投证券·PCB行业：AI PCB需求放量、高阶升级趋势明确，打开设备耗材新空间（2026-07-07）

正文以 pdftotext -layout 提取为主，关键数字回到原文页核对：P7（全球 PCB 与 AI Server 增速）、P23-P26（高多层/HDI/M7-M9）、P41-P49（相关公司梳理与经营数据）。未发现扫描件或严重破碎表格。

一句话论点

AI 算力正在把 PCB 从“普通连接板”推向“高多层、高阶 HDI、低损耗材料、精密互连平台”。中信建投的核心增量判断不是单纯看 PCB 板厂出货，而是看 高端化升级如何同时抬升设备与耗材价值量: 钻孔、曝光、压合、电镀与钻针/PCBA 设备都会跟随板层、孔结构、材料等级和线路精度一起升级。

核心逻辑链

  1. 需求侧（事实+判断）：AI Server 出货增速显著高于整体服务器。TrendForce 口径，2023-2026 年全球 AI Server 出货同比约 34.6% / 46.0% / 24.2% / 28.3%，而 2026 年全服务器行业出货增速约 12.8%（原文 P7）。中信建投据此判断，PCB 增量已经从“量”走向“量+质”。
  2. 产品侧（事实+判断）：AI 服务器相关 PCB 从传统 10-16 层抬升至 20-30 层或更高，并向高多层、高阶 HDI、低损耗材料演进。高多层与高阶 HDI 的扩张是主线，材料端从 FR-4 向 M7-M9 低损耗/超低损耗平台迁移，工艺端则加速导入 mSAP。
  3. 制程侧（事实+判断）：高端 PCB 的竞争不再只是线宽线距，而是“孔、铜、线、对位”系统能力。高阶 HDI 需要多次压合、激光对准、填铜、POFV、背钻和高精度阻焊；mSAP 通过超薄铜箔+图形电镀+闪蚀，把线宽/线距稳定做到 15-25μm 甚至更细。
  4. 设备侧（判断为主）：技术升级会依次传导到 钻孔→曝光/LDI→压合→电镀→PCBA。机械钻孔要适应厚板、背钻和高精度定位；LDI 适合细线路与高精度对位；压合成为高层数与高良率瓶颈；VCP/移载式 VCP 受益于 HDI 与 mSAP；高端算力板卡组装则拉动锡膏印刷、点胶与测试设备。
  5. 耗材侧（判断为主）：钻针是最典型的快消耗材受益环节。单板钻孔总量上升、单孔耗针数增加、单支寿命缩短三重叠加，使 AI PCB 对钻针形成倍数级拉动；同时 M7→M9、Q 布、厚板与微孔加工难度提升，进一步推升高端钻针价格带。

测算假设链

  • 假设1：AI Server 继续从 GPU/ASIC 单板扩展到整柜级互连系统，PCB 需求从计算板向交换/网络/供电/控制环节扩散。
  • 假设2：高多层与高阶 HDI 升级持续，14 层以上与三阶以上 HDI 增速显著高于行业平均。
  • 假设3：112G→224G→1.6T 继续推动材料从 M7/M8 向 M9 升级，Q 布/HVLP4 渗透率提升。
  • 假设4：mSAP 成为精细线路的关键升级方向，曝光、电镀、钻孔和检测设备同步受益。
  • 假设5：钻针景气由“板更厚、孔更小、材料更硬”三项共同驱动，而非只由下游面积增长驱动。

竞争格局 / 受益标的

以下为中信建投报告观点转述，不构成事实性推荐或投资建议。

  • PCB设备：大族数控、芯碁微装、东威科技、合锻智能。
  • PCB钻针：鼎泰高科、中钨高新、欧科亿、民爆光电、新锐股份。
  • PCBA设备：凯格精机、劲拓股份、博杰股份。
  • 报告逻辑上，受益排序更偏向“高端化受益最直接的制程环节”，即钻孔/曝光/电镀/钻针，而不是普通低端扩产设备。

催化剂与时间点

  • AI Server 出货继续高增并验证 2026 年 28.3% 增速假设
  • Rubin 及后续平台推动板层、材料和互连复杂度继续抬升
  • 224G / 1.6T 互连带动 M9、Q 布和 HVLP4 材料放量
  • mSAP 在 AI PCB 与高阶 HDI 场景的量产渗透
  • 钻针高端化从“逻辑成立”走向“量价兑现”

风险提示

  1. AI 服务器及算力资本开支不及预期。
  2. PCB 厂商扩产及设备订单兑现不及预期。
  3. 技术路线变化及行业竞争加剧风险。

与前篇观点对比

  • 与 2026-07-01-PCB设备半导体化-广发证券-一代工艺一代设备 相比，中信建投的视角更偏 “先把 AI PCB 的产品升级讲透，再传导到设备与耗材”；广发更强调“半导体化”和估值重塑，中信建投更强调“高多层/高阶 HDI/M7-M9/mSAP”这些需求端与工艺端细节。
  • 与 2026-07-06-PCB钻针行业深度-慧博汇编-量价逻辑竞争格局产业链梳理 相比，本篇对钻针的展开更短，但胜在把钻针放回 AI PCB 全链条升级 中理解；慧博那篇则更像钻针子行业专篇，份额、棒材和新进入者拆得更深。
  • 与 PCB与封装基板 既有叙事相比，本篇强化了一个中观结论：PCB 景气不能只看板厂产能，要同时看板层、HDI 阶数、材料等级和孔结构升级，否则容易低估上游设备/耗材弹性。
